## 🚀 Три способа использования

### 1. Python Console (Самый простой)
```bash
python3 remote_lua_console.py -H 192.168.0.107 -p 9998
```

### 2. SSH Tunnel (Самый безопасный)
```bash
ssh -L 9998:localhost:9998 user@192.168.0.107
python3 remote_lua_console.py -H 127.0.0.1 -p 9998
```

### 3. VS Code Debug (Самый удобный)
```
F5 → Выбрать конфигурацию → Debug Console (Ctrl+Shift+Y)
```

## 📝 Следующие шаги

1. **На Windows ПК:**
   - Установи Script Extender
   - Настрой `ScriptExtenderSettings.json`
   - Открой порт 9998 ИЛИ установи SSH сервер
   - Запусти игру

2. **На Linux ПК:**
   - Проверь доступность: `nc -zv 192.168.0.107 9998`
   - Тестовая команда: `python3 remote_lua_console.py -e "print('Test')"`

3. **Начни работу:**
   - Читай **RUN.md** для детальной инструкции
   - Используй **QUICK_START.md** для примеров команд
